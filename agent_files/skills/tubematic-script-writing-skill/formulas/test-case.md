# Test Case, Answered Last

`formula_id`: `test-case`

Pose one famous concrete case in the first sentence, walk the rules from easiest to hardest, and answer the case in the last sentence.

## Length

150 to 300 words across every segment's `voice`. Stay inside the band: the beats below are sized for it.

## Beats

In this order. A share is the part of the script's words the beat covers; hold each within a few points.

| Beat | Share of the script | Its job |
|---|---|---|
| The case | 0 to 10% | Would this famous concrete case count? Asked in the first sentence. |
| Fair question | 10 to 14% | Why the question is a reasonable one. |
| Rules, easiest first | 14 to 45% | One rule per sentence, with one 'you would think so, but' among them. |
| Where the rules run out | 45 to 80% | The official list is incomplete: who wrote it and why. |
| Precedent | 80 to 92% | A known case the rules did settle. |
| The case answered | 92 to 100% | The last sentence. |

## Openings

Draft one opening from each of three shapes. The type goes in `hooks[].type`.

| Type (`type`) | Shape |
|---|---|
| Question (`question`) | Would [famous concrete case] count as [category]? |
| What if (`what_if`) | What if [famous case] had to follow the rules of [system]? |
| Belief, then break (`myth`) | Everyone says [famous case] is [category]. The rules say something else. |

## What holds the viewer

The case is on screen from the first second and is not answered until the last, so every rule is heard as evidence for or against it.

## Ending

The case's answer. Nothing after it.

## Pitfalls

- Answering the case early
- Rules listed with no case to test them on
- A rule with no source
- A hedge where the answer belongs

## Template

The shape of the whole script with the facts left out. Fill it with this topic's facts; never keep its wording.

> Would [concrete case] count as [category]? Fair question. [Category 1] is easy: [rule]. You would think [category 2] means [naive reading], but [real rule]. Then there is [the official list], which is incomplete because [who wrote it]. Proof: [a known case]. Which makes [concrete case] [answer].
