# Tubematic — Usage

You run Tubematic from its web dashboard; agent slash commands are an optional alternative. Day-to-day
use is documented in the user guide, under `docs/`:

- **[Quickstart](docs/quickstart.md)** — from a fresh install to your first video.
- **[Using Tubematic](docs/user-guide/03-using-tubematic.md)** — how the pipeline works from your
  side, the ways to generate videos, the controls that limit cost, where to change each setting
  later, a typical day, agent commands, pausing and monitoring.
- **[The Dashboard](docs/user-guide/04-dashboard.md)** — every page, the decisions you make there,
  and the settings page.
- **[Settings](docs/user-guide/05-settings.md)** — every setting and its default.
- **[Troubleshooting](docs/user-guide/08-troubleshooting.md)** — symptoms and their usual causes.

Installing is covered in `INSTALL.md`, upgrading in
[docs/user-guide/07-upgrading.md](docs/user-guide/07-upgrading.md), and removing Tubematic in
`UNINSTALL.md`.
