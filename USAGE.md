# Tubematic: Usage

You run Tubematic from its web dashboard, at `http://localhost:3000`. The user guide under `docs/`
covers day-to-day use:

- [Quickstart](docs/quickstart.md): from a new install to your first video.
- [Using Tubematic](docs/user-guide/03-using-tubematic.md): the daily routine, where topics come
  from, and how to limit what research costs.
- [The Dashboard](docs/user-guide/04-dashboard.md): each page, and the decisions you make there.
- [Settings](docs/user-guide/05-settings.md): each setting and its default.
- [Publishing](docs/user-guide/06-publishing.md): posting videos to your social accounts.
- [Troubleshooting](docs/user-guide/08-troubleshooting.md): symptoms and fixes.
- [Command Reference](docs/user-guide/15-command-reference.md): every command you run on this
  machine.

Installing is covered in `INSTALL.md`, upgrading in
[Upgrading](docs/user-guide/07-upgrading.md), and removing Tubematic in `UNINSTALL.md`.
